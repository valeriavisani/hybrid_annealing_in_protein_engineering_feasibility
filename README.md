# hybrid_annealing_in_protein_engineering_feasibility



## Third-party material

Two files in this repository come from, or are derived from, the
[quantum-protein-folding](https://github.com/stfc/quantum-protein-folding)
repository by D. Manawadu and A. Agathangelou, associated with the paper:

> A. Agathangelou, D. Manawadu, I. Tavernelli, "Quantum Algorithm for Protein
> Side-Chain Optimisation: Comparing Quantum to Classical Methods",
> [arXiv:2507.19383](https://arxiv.org/abs/2507.19383) (2025).

- `create_energy_files.py`: adapted from their energy-file generation script;
  the modifications are listed in the header of the file.
- `4residue.pdb`: used unmodified, for testing only.
